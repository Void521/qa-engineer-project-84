Учебный проект Хекслета: https://ru.hexlet.io/programs/qa-engineer

Как это должно работать: https://products-store-ru.hexlet.app

## Стек

Проект тестирования интернет-магазина: https://products-store.hexlet.app/

## Содержание файлов

- `about.yml` — описание профессиональных навыков тестировщика.
- `requirements.yml` — описание функциональных, нефункциональных и неявных требований проекта.
- `test-cases.yml` — подробные тест-кейсы для проведения тестирования.
- `testing-report.yml` — результат прохождения тест-кейсов с отметкой об их успешности или провальности.
- `bugreports.yml` — подробное описание дефектов и шагов по их воспроизведению.
- `regress-report.yml` — отчёт о проведённом регрессионном тестировании и новые баг-репорты.
- `screenshots/` — скриншоты, приложенные к баг-репортам.

## Установка

Клонируйте репозиторий и перейдите в каталог проекта:

```bash
git clone https://github.com/Void521/qa-engineer-project-84.git
cd qa-engineer-project-84
```

## Использование

Откройте интернет-магазин и выполните тестирование согласно требованиям и тест-кейсам проекта.

Тестируйте функциональность приложения, фиксируйте обнаруженные дефекты и сохраняйте результаты тестирования в соответствующих файлах.

Не удаляйте и не переименовывайте этот файл или репозиторий, чтобы автоматические проверки продолжали работать.
